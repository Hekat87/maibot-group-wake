# 群唤醒 / Group Wake

指定群平时**完全不说话**，只有被 @ 的时候短暂醒过来，窗口结束自动回到静默。

- 静默期间消息照常入库、照常进上下文，但**不进 Planner、不花 token**
- 被 @ 之后按正常的频率说话，窗口时长可配
- 一条配置管多个群

## 安装

1. 把本仓库整个目录放进 `<MaiBot>/plugins/`
2. 启用插件，按下面填群号
3. 重启 MaiBot（或等文件监视器热加载）

## 配置

```toml
[group_wake]
groups = ["123456789"]   # 要静默的群号，可以写多个
wake_seconds = 120       # 被 @ 之后保持可说话的秒数
silent_adjust = 0.0      # 平时倍率，0 = 完全静默
wake_adjust = 1.0        # 唤醒后的倍率，1.0 = 按该群正常频率
```

也可以直接在 WebUI 的插件页里改，热生效。

## 注意

目标群的 `talk_value` 必须大于 0（建议 0.01~0.2）。如果配了 `talk_value = 0` 的规则，
`0 × 任何倍率` 还是 0，@ 也醒不过来；插件会在日志里提醒。
